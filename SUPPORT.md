# Support for Deucarian Gameplay Foundation

Use [GitHub Issues](https://github.com/Deucarian/Gameplay-Foundation/issues) for reproducible defects in identifiers, deterministic random, clocks, ticks, tags, stats, modifiers, or validation primitives; documentation gaps; and narrowly scoped feature requests.

Include the package version, Unity editor and .NET compatibility context, deterministic seed or input data when relevant, the smallest pure-C# reproduction, and expected versus actual results.

`main` is the stable package channel. `develop` is a preview channel and may change before promotion. Please reproduce against the applicable current channel before reporting an older snapshot.

Do not disclose vulnerabilities or private game data in an issue. Follow [SECURITY.md](SECURITY.md) for private security reports.

Support is provided on a best-effort basis. Domain-specific combat, progression, saving, UI, and networking behavior is outside this package's pure-C# foundation boundary.
